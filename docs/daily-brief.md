# 每日简报（个人晨报 + 历史准确率复盘）

> English: [daily-brief_EN.md](daily-brief_EN.md)

覆盖 #149 个人晨报、#466 准确率复盘与 #1131 已观测财报事件上下文。

- 默认关闭；本地日最多一次；既有调度器与通知渠道。
- 内容：持仓成员（不比较未统一币种的金额）、隔夜要点、近期财报事件上下文、昨日分析、自选、诚实准确率。
- `DAILY_BRIEF_QUIET_WHEN_EMPTY` 无实质内容时跳过推送。
- 非有限指标显式隐藏为不可用，输出上限为 24,000 字符。
- 通知复用统一 `report` 路由及逐渠道结构化结果；单渠道失败不阻塞分析。`report_type=daily_brief` 可作为 #181 收件箱权威来源。
