## 2. 目标架构选项 — 需要决策

Issue #368 描述的任务导向目标 IA 与当前五域 Shell 已部分重合。剩余决策主要在**深度**、**信号/审批入口**、以及首页/Agent/设置扩展幅度。

### 选项 A — 稳定当前 Shell（默认推荐）

**形态**：保持五主域；信号走铃铛/面板；审批走首页/面板；不新增顶级域。

| 优点 | 缺点 |
| --- | --- |
| 与现码、UI 手册、测试一致 | 非管理员仍可能难发现审批 |
| 迁移成本与深链风险最低 | 首页仍密于「三块」目标 |
| 符合「禁止新增顶级域」 | 技能后验仍为研究子项 |

**适用**：后续只做内容/空态打磨，不再做导航大改。

### 选项 B — 完整落地 #368 域图

**形态**：注意力中枢首页；单一信号中心；研究 Market/Discover/Workbench/Backtest；组合持仓+风险；Agent 对话/过程/人设；设置系统/插件/通知/用量/API。

| 优点 | 缺点 |
| --- | --- |
| 任务导向；外部评审倾向此图 | 需多 PR 内容改造，冲突面大 |
| 频率分层清晰 | 与进行中的页面拆分 PR 易撞车 |
| 移动底栏故事完整 | 底栏本身是独立 PWA 工程 |

**适用**：维护者接受分阶段 epic，并在机械卫生合并后启动。

### 选项 C — 将信号中心（或审批）提升为主导航

**形态**：信号中心（及可选审批）升为顶级或首页子项。

| 优点 | 缺点 |
| --- | --- |
| 降低对铃铛/cmd+k 的依赖 | 违背「信号不占底栏 / 单二次页」意图 |
| 贴近早期十项主导航肌肉记忆 | 重新拉宽顶级 IA |

**适用**：仅当数据证明铃铛/面板无法修复入口失败率。

### 选项 D — 进一步收缩研究子项

**形态**：减少研究子链（例如技能后验仅概览可达；发现并入分析发起）。

| 优点 | 缺点 |
| --- | --- |
| 小屏侧栏更短 | 隐藏真实工具；影响概览卡片与深链 |
| | 评估者路径变差 |

**适用**：测量到研究飞出菜单噪声后再议。

## 3. 若选 B 时的约束（来自 #368）

1. 首页默认：今日焦点 + 待办 + 信号摘要；其余默认折叠。  
2. 全系统唯一信号中心实例；过滤器经 URL/会话表达。  
3. 分析是三分段工作台，不平行拆二级页。  
4. 二级页空态须有主操作。  
5. 桌面专属能力不得在 Web/PWA 留下死入口。  
6. cmd+k 须索引二级页与关键操作（机械 PR 部分覆盖）。  
7. 铃铛是信号/告警/审批的第一入口并深链。  
8. 组合页头预留多组合切换位。  
9. #161 拆成「导入图表/文档到分析」与「截图识别持仓」。

纸交易归组合类型；插件市场默认在设置内，直至 #368 阈值。
