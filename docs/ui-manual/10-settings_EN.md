# 10 Settings: make the minimum path work, kindly

Hi. Settings looks crowded, but you usually only need three wins first:

1. **A model that connects** (or there is no report),  
2. **A few watchlist codes** (or there is no “who”),  
3. **(Optional) one notify channel that tests green** (or rules fire into silence).

Everything else can wait until the main path works.

> 💡 UI clicking only—cloud signups and Docker ports live in the [full guide](../full-guide.md) and [beginner setup](../beginner-client-setup_EN.md).

> ⚠️ Habit: **Save → test → leave**. Typing without Save is the #1 “I filled it but Home still complains” story.

---

## Open Settings

Sidebar **Settings**, `/settings`, Home **Start guided setup**, or deep links like `/settings?section=ai_models&view=connections`.

Left rail = sections; some have views. Beginner mode may hide advanced items.

---

## Save discipline

Edit → **Save configuration** → success toast → then test connection/push. Watch the unsaved badge; some fields autosave—wait for “saved”.

---

## First-time: readiness

Guided setup / Overview readiness chips → fix “needs action” (usually AI + watchlist) → Save each time → optional smoke run → Home banner should ease.

---

## AI & Models

**Model Access:** add provider → paste key (+ base URL if needed) → fetch/select models → set **primary analysis** model → optional Agent model → **Save** → **Test connection**.

**Local models:** catalog, pull, activate; respect delete protections.

**Task routing / generation backend:** default cloud path is the calm choice. Local CLI generation is experimental, not fully offline, and may not support Agent tools. “Fallback generation backend” is not the same as “backup model in the connection editor”.

**Reliability:** leave defaults unless you are chasing a specific failure.

---

## Watchlist

Comma-separated codes (`600519,hk00700,AAPL`). Paste from tables often works; Save normalizes separators. Start with 1–3 familiar names.

---

## Data sources

News keys improve event context; technical-only runs may still work without them. Intel sources are often default-off.

---

## Notifications & alerts

One channel you actually read → fill fields → **test push** → Save → then build rules in [Signal Center](06-signals_EN.md). Alerts & Automation is routing/rate limits; rule definitions still live under Signals → Rules.

---

## UI language vs report language

Independent. English menus + Chinese reports is fine. Theme is cosmetic only.

---

## Learn later

Conversation context, Agent behavior, usage/cost, backtest engine, scheduling (needs a long-running process), auth/password, version/updates, **config backup** before reinstall, developer diagnostics when debugging.

---

## Use cases

Zero to first report; English UI + `zh` reports; silent Telegram → test push; chat tools blocked on local CLI → cloud Agent path; export backup before desktop reinstall.
