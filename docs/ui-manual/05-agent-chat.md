# 05 问股对话（Agent）：读完报告后，把不懂的问清楚

你好。问股页是一个 **可以多轮聊天** 的研究助手。它最适合的用法不是「从零让它保证你赚钱」，而是：

> 我已经有一份报告了，这一段我没看懂 / 我想确认失效条件 / 我想对比两只票的差异——我们慢慢聊清楚。

侧栏上你可能看到的名字是 **Agent**；进到页面后标题常常是 **问股**。同一个入口，别被文案绕晕。

> 💡 **和工作台怎么分工？**  
> - **分析工作台**：产出结构化报告、历史记录、可提取的信号  
> - **问股**：在报告或指定标的上继续追问  
> 更稳的顺序永远是：**先报告，后追问**。

> ⚠️ 对话内容只供研究，**不构成投资建议**。闲聊语气不等于下单指令。

## 怎么打开问股

| 方式 | 说明 |
| --- | --- |
| 侧栏 **Agent** | 最直接 |
| 地址 `/chat` | 可收藏 |
| 报告上的 **继续问股** | 通常会带上当前股票上下文，推荐 |
| 命令面板 | 搜「问股」「Agent」「对话」 |

---

## 第一次聊天：请这样开始

1. 确认 **当前聊的是哪只股票**。从报告点进来一般已经对了；不确定就在问题里写代码，例如「只讨论 600519」。  
2. 第一问尽量只问一件事，例如失效条件，而不是「全面分析并告诉我能不能满仓」。  
3. 等回复结束后，再问第二问（价位依据、主要风险等）。  
4. 换股票时：要么 **新开对话**，要么清楚写「请切换到 300750，不要混入上一只」。  
5. 有用的结论，可以导出，或去信号中心做成规则/手工信号。

### 空状态里的示例句，可以改得更研究向

界面可能提示「分析 600519」「茅台现在能买吗」。  
更稳妥的改法是：

- 「请列出 600519 当前建议的失效条件，用条目说明。」  
- 「用白话解释支撑与压力，并说明依据是技术位还是事件。」  
- 「不要给出仓位比例，只讨论观察条件。」

## 策略 Skill：要选吗？

可选。它改变提问与证据的侧重点（趋势、质量、事件等，以列表为准）。

- 第一次追问：建议 **不选**，减少变量。  
- 你明确想用某种风格时再选。  
- 它仍然 **不是** 稳赚开关。

---

## 连接失败、发不出去时

请先别怀疑「是不是我问得不对」。按下面顺序检查：

1. 设置里模型是否保存成功、测试连接是否通过。  
2. 问股是否需要工具调用，而当前生成后端是 **仅本地 CLI、不支持工具**——到设置看生成后端 / 任务路由提示。  
3. 网络与后端服务是否在运行。  
4. 通知失败：只影响推送，不等于对话本身失败；去设置做测试推送。

---

## 省额度的聊法（友好建议）

问股往往比「再跑一整份 detailed 报告」更灵活，但长会话也会吃 token。

- 先用工作台 brief 出短报告，再只追问 1～2 个不懂的点。  
- 开启上下文压缩（若有），并确认保存成功。  
- 发现模型开始「忘」前文：新开对话，把关键结论粘贴成三行摘要再继续。  
- 不要让它重复生成你已经在报告里读过的整章。

## 使用案例

### 案例 A：报告看完，只卡在失效条件

从历史报告点继续问股 →  
「请用条目列出本建议的失效条件；若收盘跌破哪一价位应重新评估？」→  
把关键价位记到信号规则（可选）。

### 案例 B：差点串股

不推荐：「那另一只呢？」  
推荐：「请切换到 300750，只讨论估值与负债风险，不要混入 600519。」

### 案例 C：想对比两只美股

「对比 AAPL 与 MSFT 近阶段趋势差异，列出各自主要风险，不要给出仓位指令。」

### 案例 D：我已持仓，只想要观察框架

「我已持有 600519。请只讨论加仓或减仓前应观察的条件，不要替我决定仓位比例。」
