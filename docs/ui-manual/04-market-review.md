# 04 大盘复盘

大盘复盘回答的是：

> **今天（或这一阶段）整个市场大概什么氛围？**

它不回答「某一只股票该不该买」。请和大盘结论保持一点距离：指数强，不代表你手里的票一定强。

> 💡 **和个股分析的差别**  
> - **分析工作台**：研究一只股票  
> - **大盘复盘**：研究市场整体（指数、涨跌家数、板块、情绪等）  
> - **发现**：筛候选股票（另一页）

> ⚠️ 复盘内容仅供研究，**不构成投资建议**。

---

## 怎么进入

| 方式 | 路径 |
| --- | --- |
| 导航 | **研究** → **大盘复盘** |
| 地址 | `/research/market` |
| 命令面板 | 搜「大盘」「复盘」 |
| 一键触发深链 | `/research/market?action=run`（部分首页待办会带；进入后可能自动跑一次） |

若你只是想翻历史，请用干净地址 `/research/market`，不要随手加 `action=run`，以免误触发。

---

## 适合什么时候用

| 场景 | 建议 |
| --- | --- |
| 收盘后 10 分钟 | 跑一次，记下主线板块与两条风险 |
| 盘中想摸温度 | 可以跑，但要把「日线未完成」当头等大事 |
| 已经有历史 | 优先打开历史，不必为「再看一眼」天天重跑 |
| 和自选结合 | 复盘找方向 → 回工作台研究具体代码 |

---

## 页面上你会看到什么

1. **触发复盘** 按钮：提交一次市场级任务。  
2. **反馈区**：提交中 / 进行中 / 完成 / 失败 / 超时。  
3. **复盘历史**：以前的市场日记；可多选删除。  
4. **报告区**：选中一条后的摘要与正文。  
5. （可选）**运行流**：任务内部阶段，排障用。

### 操作步骤（收盘后推荐）

1. 进入大盘复盘页。  
2. 点 **触发复盘**（文案以界面为准）。  
3. 等完成；失败时读错误（模型、网络、数据源）。  
4. 在历史中打开最新一条。  
5. 按下面顺序读：指数 → 广度 → 板块 → 风险/数据质量。  
6. 最多挑 1～2 个方向，回 [分析工作台](03-analysis-workbench.md) 做个股。

---

## 报告里常见块（怎么读才不慌）

| 区块 | 你在看什么 | 容易误读成 |
| --- | --- | --- |
| 主要指数 | 大盘方向 | 「指数涨 = 我该满仓」 |
| 广度 | 涨跌家数等 | 「赚钱效应一定持续」 |
| 板块 / 概念 | 今天谁领涨领跌 | 「领涨板里每只都能追」 |
| 风险摘要 | 要注意什么 | 「官方下单指令」 |
| 数据质量 | 是否降级、是否盘中 | 忽略后过度自信 |

---

## 术语（白话）

| 术语 | 含义 |
| --- | --- |
| 广度 | 上涨的多还是下跌的多，赚钱效应散不散 |
| 板块轮动 | 资金在不同主题间换来换去 |
| 日线未完成 | 今天的 K 线还没收死，结论要打折 |
| 运行流 | 任务卡在哪一步的拆解 |
| recordId | 某条历史复盘的编号 |

---

## 使用案例

**案例 A：收盘后极简流程**  
触发 → 只记「主线板块 + 两条风险」→ 自选里最多 2 只相关票去做个股分析。

**案例 B：盘中别冲动**  
盘中触发看到大涨叙事 → 发现未完成日线/降级提示 → 只当温度计，等收盘再决定加码研究。

**案例 C：只读历史**  
打开干净 URL → 对比昨天与今天的板块是否切换 → 省一次模型额度。

**案例 D：失败了**  
错误指向模型 → 设置里测连接；指向数据 → 查数据源；修好后只触发一次。
