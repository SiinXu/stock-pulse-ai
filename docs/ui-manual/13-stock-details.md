# 13 个股工作区：先看行情图，再决定要不要跑 AI

你好。个股工作区是单只股票的 **行情 + K 线** 页面。地址长这样：

`/stocks/600519` 或 `/stocks/AAPL`

它适合快速核价、调周期看图；**完整 AI 报告** 仍要去 [分析工作台](03-analysis-workbench.md)。

> ⚠️ 行情为尽力获取，可能延迟或缺失；仅供研究，**不构成投资建议**。

---

## 怎么进入

| 方式 | 说明 |
| --- | --- |
| 地址栏 | `/stocks/:stockCode` |
| 命令面板 | 输入代码（结果以当前版本命令为准） |
| 其它页外链 | 部分列表可能链到本页 |

查询参数（浏览器前进后退可恢复）：

| 参数 | 含义 | 范围 |
| --- | --- | --- |
| `period` | 日 / 周 / 月 | `daily` / `weekly` / `monthly` |
| `days` | 回看天数 | 1～365，默认约 90 |

示例：`/stocks/AAPL?period=daily&days=180`

---

## 页面上有什么

1. **页头**：名称或代码 + **刷新**  
2. **快捷按钮**：加入自选、分析、创建规则（到信号中心）  
3. **报价卡**：现价、涨跌、开高低、昨收、量额等  
4. **周期与天数**：改完需要 **应用**（把草稿写进 URL）  
5. **K 线图** + **OHLCV 明细表**

代码无效时，会看到无效说明——改对代码再进。

---

## 跟着做

### 快速核价

打开 `/stocks/600519` → 看报价 → 结束。不必每次都跑 AI。

### 看 180 日日线再分析

1. 打开代码页。  
2. 周期选日线，天数填 180，点应用。  
3. 读图与表格。  
4. 点 **分析** → 工作台带上代码 → 生成报告。  
5. 若要到价提醒：点创建规则 → 信号中心规则 Tab。

### 加入自选

点 **加入自选**；成功后按钮状态会变化。失败时看错误提示（网络/权限/配置）。

---

## 和报告页的差别

| | 个股工作区 | AI 报告 |
| --- | --- | --- |
| 内容 | 行情与 K 线 | 结论、风险、叙事 |
| 是否调用大模型 | 本页本身不调用 | 通过工作台任务调用 |
| 典型问题 | 「现在价多少」 | 「逻辑与风险是什么」 |

---

## 使用案例

**盘中瞄一眼** → 只看报价。  
**周末复盘图** → 周线 + 合适天数 → 再决定要不要重跑报告。  
**从 K 线到规则** → 目测压力区 → 创建价格规则。  
**代码写错** → 无效态 → 换成规范代码（港股注意 `hk`）。
