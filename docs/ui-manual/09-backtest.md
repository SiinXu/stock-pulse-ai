# 09 回测

回测页用来回答：

> 过去一段时间，系统给出的 AI 建议，事后看起来是偏乐观、偏保守，还是样本太少啥也看不出来？

- 这是 **对已经产生的建议做事后验证**，不是完整量化回测 IDE。  
- 它 **没有** 替你做复杂滑点、组合优化、实盘成交重放的承诺。  
- 样本少时，任何漂亮百分比都可以先当故事看。

> ⚠️ 回测指标 **不构成** 未来收益承诺，也不是你的真实成交单。

---

## 怎么进入

| 方式 | 路径 |
| --- | --- |
| 导航 | **研究** → **回测** |
| 地址 | `/research/backtest` |
| 命令面板 | 搜「回测」 |
| 旧地址 | `/backtest` 一般会跳到规范路径 |

可收藏参数示例：

`/research/backtest?code=600519&window=30&phase=all`

| 参数 | 含义 |
| --- | --- |
| `code` | 只看某一只 |
| `window` | 回看天数（有上限，常见约 120，以界面为准） |
| `from` / `to` | 日期范围 |
| `phase` | 盘前/盘中/盘后等阶段过滤 |
| `page` | 分页 |

---

## 什么时候来，什么时候先别来

| 场景 | 建议 |
| --- | --- |
| 已经用了几周 | 选真实使用过的窗口再跑 |
| 刚装好、几乎没报告 | 可以跳过；样本为 0 很正常 |
| 只关心一只长线票 | 加 `code` 下钻 |
| 和信号中心后验一起看 | 中心偏单条生命周期；本页偏批量事后统计 |

---

## 操作步骤

1. 进入回测页。  
2. （可选）在紧凑股票框输入代码、名称、拼音或别名并从模糊推荐中选择，也可填写窗口天数、日期和阶段。
3. 点 **筛选** 只刷新下方结果和统计；点 **运行回测** 才会生成或重算评估。
4. 先看 **样本数**，再看方向准确率、胜率等。  
5. 无结果时读页面诊断（样本不足、冷却中、范围太窄等），不要狂点。

无效评估窗口会保持输入控件高度不变：输入框显示错误状态，具体原因通过屏幕阅读器提示提供，不再额外占用尾部控件。评估窗口模式切换与筛选加载也会保持控件宽度稳定，避免工具栏抖动；筛选按钮的 tooltip 会再次说明它不会重跑回测。

## 指标怎么读

| 概念 | 含义 | 注意 |
| --- | --- | --- |
| 方向准确率 | 涨跌方向是否和建议同向 | 震荡市会很难看或很偶然 |
| 胜率 | 有明确胜负时的比例 | **先看样本数** |
| 模拟收益 | 按规则模拟的参考 | 没算你的真实摩擦与情绪 |
| 止盈止损触及 | 计划价有没有碰到过 | 没写计划的信号参考弱 |
| 无法评估 | 太新、缺数据、冷却中 | 正常桶，不是坏了 |

过新的记录可能还在 **冷却窗口**，暂时进不了统计——这是保护，不是系统偷懒。

---

## 和信号中心「再评估」的差别

| | 信号中心 review | 本回测页 |
| --- | --- | --- |
| 入口 | `/signals?tab=review` | `/research/backtest` |
| 更适合 | Decision Signal 生命周期 / outcome 引擎 | 历史建议批量事后表现 |

两边都是研究工具。设置里的「回测 → 引擎」属于更进阶的开关。

---

## 使用案例

**案例 A：周末 15 分钟**  
`window=30&phase=all` → 样本是否大致够看 → 若准确率乱跳，去信号中心看是不是大量 `watch` 或盘中阶段 → 调整自己的使用习惯，而不是立刻换模型赌运气。

**案例 B：单股信任校准**  
`code=600519&window=60` → 是否翻烧饼 → 结合报告历史趋势一起看。

**案例 C：刚装好**  
空结果 → 正常。先去工作台积累报告，两周后再来。
