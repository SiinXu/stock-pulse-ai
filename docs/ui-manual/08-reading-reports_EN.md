# 08 Reading reports: a calm order so long text does not win

When the first report lands, people often either read every paragraph and remember nothing, or glance at “buy/watch” and prepare to act.

A kinder method is to answer **three questions**:

1. Is the system leaning bullish, bearish, or wait?  
2. What are the main risks?  
3. If wrong, what invalidates the thesis?

If you can answer those, the report paid for itself. Jargon can wait.

> ⚠️ Even the word “buy” is a research label — **not investment advice**. Size and execution are yours.

---

## Where reports open

Workbench **History** (best), task completion CTA, Home recent analyses, Signal Center source report, or before **Continue in chat**. Market reviews: [04](04-market-review_EN.md)—do not mix with single-name action.

---

## Beginner vs professional

Beginner: shorter, more conservative. Professional: fuller structure, context quality, long markdown. brief/detailed sets density at launch. Thin beginner view does **not** always mean analysis failed—try pro or full markdown.

---

## Fixed reading order (please keep it)

1. **Conclusion & action** — direction labels (buy/add/hold/watch/reduce/sell/avoid/alert).  
2. **Scores & trend** — temperature, not a guarantee.  
3. **Key prices** — support, resistance, stop ideas, targets (**not promises**).  
4. **Risks first, then catalysts** — catalysts are leads to verify.  
5. **News / fundamentals** — watch timestamps.  
6. **Market position** — theme role when present; skip if evidence thin.  
7. **Phase & data quality** — premarket/intraday partial bars, degradation, quality scores.  
8–9. **Optional** attribution, full markdown, continue in chat.

### Analysis Context statuses (plain)

available / missing / fetch_failed / not_supported / fallback / stale / estimated / partial describe **what entered this model call**, not eternal provider health.

---

## On-page actions

Watchlist toggle, history trend (flip-flops?), continue in chat, run-flow diagnostics, jump to signal when extracted.

---

## Use cases

**A — Watch while price rips** — check phase/quality → resistance break? → history tone → chat about observation conditions, not guaranteed upside.  
**B — Three minutes** — action + top three risks + whether stops/levels exist.  
**C — Many missing blocks** — fix data sources → re-run same code → do not size up on bad inputs.  
**D — Signal vs report** — prefer newest report + signal lifecycle over a closed signal + ancient report.

---

## Reading discipline

Chop often means watch/hold—that can be a feature. Incomplete bars deserve less bravado. Spam re-runs cost money and noise. When unsure, **waiting is also a decision**.
