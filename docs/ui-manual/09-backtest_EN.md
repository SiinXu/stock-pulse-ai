# 09 Backtest: calibrate trust, don’t gamble the next trade

This page asks how past **AI suggestions** looked after the fact. It is not a full quant backtester.

> Metrics are **not** promises of future returns.

## Open

**Research → Backtest**, `/research/backtest`. Params: `code`, `window`, `from`/`to`, `phase`, `page`.

## When

After weeks of use. Skip on a fresh install with zero history.

## How to read

Check **sample size first**, then directional accuracy / win rate / simulated return. “Unable to evaluate” and cooldown windows are normal. Few samples → ignore flashy percentages.
