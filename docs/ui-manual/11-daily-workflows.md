# 11 日常工作流与界面常见问题

本章把前面模块串成「每天怎么用」。如果你只能记住一篇，记住这一篇即可。

> 💡 **核心原则**  
> 少而稳：固定几个入口，先读结论与风险，再决定要不要深挖。不要同一天对同一只股票无意义连跑十几次。

## 推荐工作流

### A. 每天约 5 分钟（维护型）

```mermaid
flowchart LR
  H[首页焦点] --> S[信号中心扫一眼]
  S --> P[持仓风险]
  P --> Q[疑问股: 报告或问股一句]
```

1. 打开 **首页**（`/`），看焦点与待办。  
2. 打开 **信号中心**（通知铃「查看全部」、命令面板搜「信号」，或直链 `/signals`——**不在**一级侧栏），只看 `active`（仍有效）的信号。  
3. 若有持仓，打开侧栏 **组合**（页面标题多为「持仓」，`/portfolio`）看风险与异常信号。  
4. 对仍有疑问的 1 只股票：打开最近报告，或侧栏 **Agent / 问股**（`/chat`）追问一句「失效条件是什么」。

**建议配置**：通知不要全开到「所有渠道狂推」；先保证能收到，再慢慢加渠道（见 [10 设置](10-settings.md)）。

### B. 深度研究一只股票（30～60 分钟）

0. （可选）若还没有标的：先到 **研究 → 发现**（[12](12-discover.md)）用热点或策略生成候选，再点「分析」。  
1. 在 **研究 → 分析工作台**（`/research/analysis`）提交该股（可选策略 Skill）。  
2. 任务完成后按 [08 阅读报告](08-reading-reports.md) 顺序阅读。  
3. 用 **历史趋势** 对比前几次结论是否来回翻烧饼。  
4. 用 **Agent / 问股** 追问：观察点、失效条件、与同业对比（写清代码）。  
5. 若需要盯盘，在 **信号中心 → 规则**（`/signals?tab=rules`）添加价格或涨跌幅规则（先只用简单规则）。

### C. 周末复盘自己的使用方式

1. 运行 **研究 → 回测**（`/research/backtest`），看历史建议方向是否长期有用。  
2. 在信号中心 **再评估与统计**（`/signals?tab=review`）查看后验与「有用 / 无用」反馈。  
3. 回到 **设置** 微调模型或默认策略；**不要**靠疯狂改自选制造噪音。

## 界面常见问题

**点了分析一直转圈？**  
到「运行中任务」看是否失败。常见原因：模型 Key 无效、额度不足、网络问题、代码格式错误。修好后再试，避免重复提交同一失败任务。

**报告语言和界面语言不一致？**  
正常。界面语言改菜单；报告语言在设置里单独配置。

**信号中心是空的？**  
需要先有成功的个股分析，并且系统从中提取了信号。非常旧的历史不一定回填。可对自选先跑一轮分析。

**持仓有了但没有 AI 建议？**  
信号是异步加载的；该股若没有 `active` 信号，会显示空占位。可先对持仓标的跑分析。

**导入 CSV 失败？**  
先用预览检查表头与解析结果；处理超卖、重复行后再提交。券商模板不完全一致时，按界面提示调整列。

**问股串股或答非所问？**  
在问题里写清当前代码；对比时写「对比 600519 和 300750」。避免把指标名（如 MACD）当成股票代码。

**首页一直提示配置不完整？**  
设置里保存是否成功？模型测试是否通过？自选是否为空？

## 安全与习惯

| 习惯 | 原因 |
| --- | --- |
| 不把 API Key 发到聊天软件截图群 | 密钥泄露会导致盗用额度 |
| 改设置必点保存 | 未保存等于未配置 |
| 研究输出当输入而非指令 | 合规与风险自担 |
| 小批量试验 | 控制费用与心智负担 |
