# 11 日常工作流：如果只能记住一篇，记住这篇

你好。前面每一章都在讲「单个房间怎么用」。这一章把它们串成 **每天可以重复的节奏**。

原则只有一句：**少而稳**。固定几个入口，先读结论与风险，再决定要不要深挖。同一天对同一只股票无意义连跑十几次，既费钱，也容易把自己搞焦虑。

> ⚠️ 所有输出仅供研究，**不构成投资建议**。

---

## A. 每天大约 5 分钟（维护型）

1. 打开 **首页**（`/`）：看焦点和待办。  
2. 打开 **信号中心**（铃铛 / 命令面板 / `/signals`——不在一级侧栏）：只扫 `active`。  
3. 若有持仓：打开侧栏 **组合**（`/portfolio`），看集中度与异常。  
4. 对仍有疑问的 **1 只**：打开最近报告，或 **Agent / 问股** 只问一句失效条件。

通知先保证一个渠道能收到，再慢慢加（见 [10 设置](10-settings.md)）。

## B. 深度研究一只股票（30～60 分钟）

0. （可选）没有标的时，先去 [12 发现](12-discover.md) 找候选。  
1. **研究 → 分析工作台** 提交该股（可先 brief / 新手）。  
2. 按 [08 阅读报告](08-reading-reports.md) 的顺序读。  
3. 用历史趋势看是否翻烧饼。  
4. 问股追问观察点与失效条件（写清代码）。  
5. 需要盯盘时，在 `/signals?tab=rules` 建简单价格规则。

## C. 周末复盘自己的用法（不是复盘行情本身）

1. **研究 → 回测**（`/research/backtest`）看历史建议的大致方向表现。  
2. 信号中心 **再评估与统计**（`/signals?tab=review`）看反馈与后验。  
3. 回设置微调模型或默认策略——**不要**靠疯狂改自选制造噪音。

## 场景速查

| 我想… | 去哪 | 温柔提醒 |
| --- | --- | --- |
| 尽快出第一份报告 | 分析工作台 | 一只票 + 新手/brief |
| 看市场温度 | 大盘复盘 | 别当个股下单指令 |
| 找候选 | 发现 | 实验能力，再进工作台 |
| 到价提醒 | 信号中心 → 规则 | 先简单价格条件 |
| 记账 | 组合/持仓 | 先建账户 |
| 改模型 | 设置 → AI 与模型 | 保存后再测试 |
| 看行情图 | `/stocks/代码` | 不是完整 AI 报告 |

---

## 常见卡住

**信号中心是空的？** 先成功跑完个股分析。  
**持仓没有 AI 建议？** 异步加载或没有 active；对持仓跑分析即可。  
**设置填了仍提示缺口？** 多半没保存或测试未通过。  
**问股发不出去？** 查模型与是否本地 CLI 限制工具调用。
