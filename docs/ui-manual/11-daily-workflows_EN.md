# 11 Daily workflows: the one chapter to keep if you keep only one

Hi. Earlier chapters teach single rooms. This one stitches a **repeatable day**.

One principle: **few and steady**. Fixed entry points; read conclusion and risk first; do not spam the same symbol a dozen times in a day.

> ⚠️ Research only — **not investment advice**.

## A. About five minutes

1. **Home** — focus and todos.  
2. **Signal Center** (bell / palette / `/signals`, not primary sidebar) — `active` only.  
3. **Portfolio** if you bookkeep — concentration and oddities.  
4. One doubtful name — latest report or one Agent question on invalidation.

## B. Deep dive (30–60 minutes)

0. Optional: [12 Discover](12-discover_EN.md) for candidates.  
1. Workbench with beginner/brief.  
2. Read via [08](08-reading-reports_EN.md).  
3. History trend for flip-flops.  
4. Chat for observation/invalidation (codes explicit).  
5. Simple price rule at `/signals?tab=rules` if needed.

## C. Weekend process review

Backtest → Signal Center review/stats → light Settings tuning—not watchlist thrashing.

## Scenario cheat sheet

First report → Workbench. Market mood → Market review. Candidates → Discover. Alerts → Rules. Books → Portfolio. Models → Settings (save then test). Charts → `/stocks/{code}`.

## Stuck?

Empty signals → run analysis. Empty portfolio AI → analyze holdings. Setup gap after typing → Save + test. Chat fails → model / tool-capable backend.
