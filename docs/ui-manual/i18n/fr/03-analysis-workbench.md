# 03 Banc d'analyse

Bonjour. Générez ici les rapports mono-titre.

> 💡 Workbench = one stock; Market review = whole market.  
> ⚠️ Recherche uniquement — **pas un conseil d'investissement**. · Each run uses model quota.

## Chemins

**Research → Analysis Workbench** · `/research/analysis` · `segment=launch|tasks|history`

## Three segments

| Segment | Use |
| --- | --- |
| Launch | Enter codes and submit |
| Tasks | Watch queue/running/fail |
| History | Open history reports |

## First report steps

1. One symbol (`600519` / `hk00700` / `AAPL`)  
2. Skip Skill first time  
3. Prefer beginner/brief  
4. Start → wait on Tasks  
5. View report
