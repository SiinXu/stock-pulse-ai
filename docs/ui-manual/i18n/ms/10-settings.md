# 10 Tetapan

Banyak medan. Tiga kemenangan dulu:

1. **Model tersambung**  
2. **Senarai pantau ada kod**  
3. **(Pilihan) satu saluran lulus ujian push**  

> Hanya klik UI. Deployment dalam panduan lain.  
> **Simpan → uji → keluar**.

## Buka

`/settings` · setup berpandu di laman utama · `section=ai_models&view=connections`

## Pemberitahuan

Saluran sering dalam bentuk **kad**. Buka satu, isi token → **ujian push** → **Simpan**.  
**Pemalam saluran** di deploy boleh menambah jenis (`docs/notifications.md`).

## Penjadualan

**Sistem & keselamatan → Penjadualan**: auto on/off, masa, larian seterusnya, “jalankan sekarang” jika dibenarkan.  
Di laman utama, **tugas berjadual hari ini** baca sahaja. Perincian: `docs/scheduled-tasks.md`.

## Rangka pelaburan

Rangka peribadi berversi: **API/backend dulu**. Selalunya belum ada editor Web penuh. Kontrak: `docs/personal-investment-framework.md`.

## Model packs (sesetengah build / sedang)

Jika ada **Import pack**: import arkib tempatan berversi → ikat snapshot → aktifkan. Tanpa butang, jangan memaksa. Masuk: **AI & Models → Local models**.
