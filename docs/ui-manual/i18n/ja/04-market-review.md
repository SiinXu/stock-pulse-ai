# 04 マーケットレビュー

こんにちは。 Market-wide temperature — not a single-name ticket.

## 入り方

**Research → Market review** · `/research/market` · avoid `?action=run` if only browsing history  

## 手順

1. Trigger review  
2. Wait for completion  
3. Open newest history  
4. Read order: indices → breadth → sectors → risks  
5. Pick 1–2 names → Workbench
