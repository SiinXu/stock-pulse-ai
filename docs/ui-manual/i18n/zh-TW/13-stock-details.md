# 13 個股工作區：先看行情圖，再決定要不要跑 AI


> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

你好。個股工作區是單只股票的 **行情 + K 線** 頁面。地址長這樣：

`/stocks/600519` 或 `/stocks/AAPL`

它適合快速核價、調周期看圖；**完整 AI 報告** 仍要去 [分析工作台](03-analysis-workbench.md)。

> ⚠️ 行情爲盡力獲取，可能延遲或缺失；僅供研究，**不構成投資建議**。

---

## 怎麼進入

| 方式 | 說明 |
| --- | --- |
| 地址欄 | `/stocks/:stockCode` |
| 命令面板 | 輸入代碼（結果以當前版本命令為準） |
| 其它頁外鏈 | 部分列表可能鏈到本頁 |

查詢參數（瀏覽器前進後退可恢復）：

| 參數 | 含義 | 範圍 |
| --- | --- | --- |
| `period` | 日 / 周 / 月 | `daily` / `weekly` / `monthly` |
| `days` | 回看天數 | 1～365，默認約 90 |

示例：`/stocks/AAPL?period=daily&days=180`

---

## 頁面上有什麼

1. **頁頭**：名稱或代碼 + **刷新**  
2. **快捷按鈕**：加入自選、分析、創建規則（到信號中心）  
3. **報價卡**：現價、漲跌、開高低、昨收、量額等  
4. **周期與天數**：改完需要 **應用**（把草稿寫進 URL）  
5. **K 線圖** + **OHLCV 明細表**

代碼無效時，會看到無效說明——改對代碼再進。

---

## 跟着做

### 快速核價

打開 `/stocks/600519` → 看報價 → 結束。不必每次都跑 AI。

### 看 180 日日線再分析

1. 打開代碼頁。  
2. 周期選日線，天數填 180，點應用。  
3. 讀圖與表格。  
4. 點 **分析** → 工作台帶上代碼 → 生成報告。  
5. 若要到價提醒：點創建規則 → 信號中心規則 Tab。

### 加入自選

點 **加入自選**；成功後按鈕狀態會變化。失敗時看錯誤提示（網絡/權限/配置）。

---

## 和報告頁的差別

| | 個股工作區 | AI 報告 |
| --- | --- | --- |
| 內容 | 行情與 K 線 | 結論、風險、敘事 |
| 是否調用大模型 | 本頁本身不調用 | 通過工作台任務調用 |
| 典型問題 | 「現在價多少」 | 「邏輯與風險是什麼」 |

---

## 使用案例

**盤中瞄一眼** → 只看報價。  
**周末復盤圖** → 周線 + 合適天數 → 再決定要不要重跑報告。  
**從 K 線到規則** → 目測壓力區 → 創建價格規則。  
**代碼寫錯** → 無效態 → 換成規範代碼（港股注意 `hk`）。
