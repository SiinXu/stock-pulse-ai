# 01 導航與頂欄

打開 StockPulse 後，中間頁面會換，但左右和上面的入口一般還在：左側（或頂部）菜單、通知鈴、搜索/命令入口、語言和主題。

先認清這些入口，後面進分析、持倉、設置時就不容易迷路。本章不講部署和配置文件，只講這些全局入口怎麼用。

> 產品輸出僅供研究學習，**不構成投資建議**。

---

## 什麼時候會用到

| 你想做什麼 | 用哪裡 |
| --- | --- |
| 不知道功能在哪 | 左側/頂部菜單 |
| 從任意頁跳到分析 | 命令面板 `Cmd/Ctrl + K` |
| 看有沒有新提醒 | 通知鈴 |
| 菜單用英文、報告用中文 | 界面語言 vs 報告語言（設置裏） |
| 暗色界面 | 主題（淺色 / 深色） |
| 開啓了登錄 | `/login` |

---

## 布局長什麼樣

寬屏常見是：左側菜單 + 中間內容 + 頂欄工具。  
手機或窄窗口裡，菜單可能收成左上角圖標或頂欄抽屜——功能還在，只是收起來了。

| 區域 | 常見位置 | 說明 |
| --- | --- | --- |
| 主導航 | 左側 / 頂欄 | 首頁、研究、組合、Agent、設置 |
| 主內容區 | 中間 | 當前功能頁 |
| 通知鈴 | 頂欄附近 | 新信號、告警 |
| 搜索 / 命令入口 | 側欄搜索或快捷鍵 | 跳轉頁面、搜股票 |

桌面客戶端和 Web 的菜單結構一致；個別桌面窗口以實際客戶端為準。

## 命令面板

| 系統 | 快捷鍵 |
| --- | --- |
| macOS | `Cmd + K` |
| Windows / Linux | `Ctrl + K` |

| 目的 | 可以輸入 |
| --- | --- |
| 跳轉 | `分析`、`持倉`、`信號`、`設置`、`首頁` |
| 找股票 | `600519`、`AAPL` |
| 大盤 | `復盤`、`大盤` |

示例：在設置頁按 `Cmd/Ctrl + K`，輸入「分析」，直接回分析工作台。

## 通知鈴

- 點某條提醒：常會跳到對應信號或歷史。  
- **查看全部**：進入信號中心。  
- 一直是空的：如果還沒跑過分析、也沒建告警規則，屬於正常情況。

---

## 界面語言、報告語言、主題

| 設置 | 改什麼 | 不改什麼 |
| --- | --- | --- |
| **界面語言** | 菜單、按鈕、提示文案 | 報告正文語言 |
| **報告語言** | 分析報告正文（設置 → 報告） | 菜單語言 |
| **主題** | 淺色 / 深色 | 業務邏輯 |

可以菜單用 English、報告用中文。兩者分開。

產品界面支持多種語言（簡中、繁中、英、日、韓、德、西、法、馬來、印尼等）；手冊多語言見 [i18n/README.md](i18n/README.md)。

---

## 登錄（開啓認證時）

1. 打開受保護頁面會跳到 `/login`。  
2. 輸入管理員密碼。  
3. 登錄成功後回到原來的頁面或首頁。  
4. 改密碼：設置 → 系統與安全 → 認證與安全。

未開啓認證時，本機部署可能直接進入業務頁。

---

## 使用案例

**迷路了**  
任意頁 → `Cmd/Ctrl + K` → 輸入「首頁」。

**看有沒有推送**  
點通知鈴 → 沒有內容就先去跑分析或建規則。

**菜單改成英文**  
在頂欄/設置切換界面語言；報告語言可繼續用中文。
