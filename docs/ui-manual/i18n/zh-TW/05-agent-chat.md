# 05 問股對話（Agent）：讀完報告後，把不懂的問清楚


> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

你好。問股頁是一個 **可以多輪聊天** 的研究助手。它最適合的用法不是「從零讓它保證你賺錢」，而是：

> 我已經有一份報告了，這一段我沒看懂 / 我想確認失效條件 / 我想對比兩隻票的差異——我們慢慢聊清楚。

側欄上你可能看到的名字是 **Agent**；進到頁面後標題常常是 **問股**。同一個入口，別被文案繞暈。

> 💡 **和工作台怎麼分工？**  
> - **分析工作台**：產出結構化報告、歷史記錄、可提取的信號  
> - **問股**：在報告或指定標的上繼續追問  
> 更穩的順序永遠是：**先報告，後追問**。

> ⚠️ 對話內容只供研究，**不構成投資建議**。閒聊語氣不等於下單指令。

---

## 怎麼打開問股

| 方式 | 說明 |
| --- | --- |
| 側欄 **Agent** | 最直接 |
| 地址 `/chat` | 可收藏 |
| 報告上的 **繼續問股** | 通常會帶上當前股票上下文，推薦 |
| 命令面板 | 搜「問股」「Agent」「對話」 |

---

## 第一次聊天：請這樣開始

1. 確認 **當前聊的是哪只股票**。從報告點進來一般已經對了；不確定就在問題裏寫代碼，例如「只討論 600519」。  
2. 第一問儘量只問一件事，例如失效條件，而不是「全面分析並告訴我能不能滿倉」。  
3. 等回復結束後，再問第二問（價位依據、主要風險等）。  
4. 換股票時：要麼 **新開對話**，要麼清楚寫「請切換到 300750，不要混入上一隻」。  
5. 有用的結論，可以導出，或去信號中心做成規則/手工信號。

### 空狀態裏的示例句，可以改得更研究向

界面可能提示「分析 600519」「茅臺現在能買嗎」。  
更穩妥的改法是：

- 「請列出 600519 當前建議的失效條件，用條目說明。」  
- 「用白話解釋支撐與壓力，並說明依據是技術位還是事件。」  
- 「不要給出倉位比例，只討論觀察條件。」

## 策略 Skill：要選嗎？

可選。它改變提問與證據的側重點（趨勢、質量、事件等，以列表為準）。

- 第一次追問：建議 **不選**，減少變量。  
- 你明確想用某種風格時再選。  
- 它仍然 **不是** 穩賺開關。

---

## 連接失敗、發不出去時

請先別懷疑「是不是我問得不對」。按下面順序檢查：

1. 設置裏模型是否保存成功、測試連接是否通過。  
2. 問股是否需要工具調用，而當前生成後端是 **僅本地 CLI、不支持工具**——到設置看生成後端 / 任務路由提示。  
3. 網絡與後端服務是否在運行。  
4. 通知失敗：只影響推送，不等於對話本身失敗；去設置做測試推送。

---

## 省額度的聊法（友好建議）

問股往往比「再跑一整份 detailed 報告」更靈活，但長會話也會喫 token。

- 先用工作台 brief 出短報告，再只追問 1～2 個不懂的點。  
- 開啓上下文壓縮（若有），並確認保存成功。  
- 發現模型開始「忘」前文：新開對話，把關鍵結論粘貼成三行摘要再繼續。  
- 不要讓它重複生成你已經在報告裡讀過的整章。

## 使用案例

### 案例 A：報告看完，只卡在失效條件

從歷史報告點繼續問股 →  
「請用條目列出本建議的失效條件；若收盤跌破哪一價位應重新評估？」→  
把關鍵價位記到信號規則（可選）。

### 案例 B：差點串股

不推薦：「那另一隻呢？」  
推薦：「請切換到 300750，只討論估值與負債風險，不要混入 600519。」

### 案例 C：想對比兩隻美股

「對比 AAPL 與 MSFT 近階段趨勢差異，列出各自主要風險，不要給出倉位指令。」

### 案例 D：我已持倉，只想要觀察框架

「我已持有 600519。請只討論加倉或減倉前應觀察的條件，不要替我決定倉位比例。」

## 術語（白話）

| 術語 | 人話 |
| --- | --- |
| 會話 Session | 一組連續多輪聊天 |
| 上下文 | 模型暫時「記得」的前文 |
| 上下文壓縮 | 壓縮歷史以省 token |
| 工具調用 | 去拉行情/新聞等實時能力 |
| 來源 agent 的信號 | 有些對話結論可能沉澱進信號中心（不保證每句都入庫） |
