# 04 大盤復盤：先看市場氣質，再挑個股


> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

你好。大盤復盤迴答的是：

> **今天（或這一階段）整個市場大概什麼氛圍？**

它不回答「某一隻股票該不該買」。請和大盤結論保持一點距離：指數強，不代表你手裡的票一定強。

> 💡 **和個股分析的差別**  
> - **分析工作台**：研究一隻股票  
> - **大盤復盤**：研究市場整體（指數、漲跌家數、板塊、情緒等）  
> - **發現**：篩候選股票（另一頁）

> ⚠️ 復盤內容僅供研究，**不構成投資建議**。

## 怎麼進入

| 方式 | 路徑 |
| --- | --- |
| 導航 | **研究** → **大盤復盤** |
| 地址 | `/research/market` |
| 命令面板 | 搜「大盤」「復盤」 |
| 一鍵觸發深鏈 | `/research/market?action=run`（部分首頁待辦會帶；進入後可能自動跑一次） |

若你只是想翻歷史，請用乾淨地址 `/research/market`，不要隨手加 `action=run`，以免誤觸發。

---

## 適合什麼時候用

| 場景 | 建議 |
| --- | --- |
| 收盤後 10 分鐘 | 跑一次，記下主線板塊與兩條風險 |
| 盤中想摸溫度 | 可以跑，但要把「日線未完成」當頭等大事 |
| 已經有歷史 | 優先打開歷史，不必爲「再看一眼」天天重跑 |
| 和自選結合 | 復盤找方向 → 回工作台研究具體代碼 |

---

## 頁面上你會看到什麼

1. **觸發復盤** 按鈕：提交一次市場級任務。  
2. **反饋區**：提交中 / 進行中 / 完成 / 失敗 / 超時。  
3. **復盤歷史**：以前的市場日記；可多選刪除。  
4. **報告區**：選中一條後的摘要與正文。  
5. （可選）**運行流**：任務內部階段，排障用。

### 操作步驟（收盤後推薦）

1. 進入大盤復盤頁。  
2. 點 **觸發復盤**（文案以界面為準）。  
3. 等完成；失敗時讀錯誤（模型、網絡、數據源）。  
4. 在歷史中打開最新一條。  
5. 按下面順序讀：指數 → 廣度 → 板塊 → 風險/數據質量。  
6. 最多挑 1～2 個方向，回 [分析工作台](03-analysis-workbench.md) 做個股。

---

## 報告裡常見塊（怎麼讀才不慌）

| 區塊 | 你在看什麼 | 容易誤讀成 |
| --- | --- | --- |
| 主要指數 | 大盤方向 | 「指數漲 = 我該滿倉」 |
| 廣度 | 漲跌家數等 | 「賺錢效應一定持續」 |
| 板塊 / 概念 | 今天誰領漲領跌 | 「領漲板裏每隻都能追」 |
| 風險摘要 | 要注意什麼 | 「官方下單指令」 |
| 數據質量 | 是否降級、是否盤中 | 忽略後過度自信 |

---

## 術語（白話）

| 術語 | 人話 |
| --- | --- |
| 廣度 | 上漲的多還是下跌的多，賺錢效應散不散 |
| 板塊輪動 | 資金在不同主題間換來換去 |
| 日線未完成 | 今天的 K 線還沒收死，結論要打折 |
| 運行流 | 任務卡在哪一步的拆解 |
| recordId | 某條歷史復盤的編號 |

## 使用案例

**案例 A：收盤後極簡流程**  
觸發 → 只記「主線板塊 + 兩條風險」→ 自選裏最多 2 只相關票去做個股分析。

**案例 B：盤中別衝動**  
盤中觸發看到大漲敘事 → 發現未完成日線/降級提示 → 只當溫度計，等收盤再決定加碼研究。

**案例 C：只讀歷史**  
打開乾淨 URL → 對比昨天與今天的板塊是否切換 → 省一次模型額度。

**案例 D：失敗了**  
錯誤指向模型 → 設置裏測連接；指向數據 → 查數據源；修好後只觸發一次。
