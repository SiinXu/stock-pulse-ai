你好，歡迎來到 StockPulse。

這份手冊按「第一次打開軟件」的讀者來寫：你可能還不熟 A 股 / 港股 / 美股代碼，也不確定「分析」「信號」「持倉」各自是幹什麼的。我們會用**親切、清楚**的語氣，把**點哪裡、爲什麼、下一步做什麼**說明白；表格用來速查，正文用來陪你走通。

寫作約定（給維護者也給讀者）：

- 先講人話場景，再給路徑與術語。  
- 重要按鈕與路由寫具體；界面文案若與手冊不一致，**以你屏幕上的為準**。  
- 中英分冊成對維護；產品 UI 還可以有更多語言。

> 💡 **溫馨提示**  
> 本產品輸出僅供**學習與研究**，**不構成投資建議**。真實買賣請自行判斷風險與合規要求。

## 入門術語速查

| 術語 | 一句話解釋 |
| --- | --- |
| **自選股（Watchlist）** | 你關心的股票代碼列表，系統會按它做批量分析或首頁摘要 |
| **個股分析** | 針對**一隻**股票生成研究報告（技術面、資訊、風險、建議等） |
| **大盤復盤** | 對整個市場（如 A 股）的盤面摘要，不是單只股票買賣建議 |
| **信號（Decision Signal）** | 系統從分析報告裡提煉出的、可查詢的「建議資產」，方便事後核對 |
| **策略 / Skill** | 可選的分析風格包（例如更偏趨勢或更偏質量），不選則用默認 |
| **支撐 / 壓力** | 價格下方可能被買盤託住的區域叫支撐；上方可能遇賣壓的區域叫壓力 |
| **止損** | 預先想好的「錯了就認錯離場」的價格或條件，用於控制虧損 |
| **界面語言 vs 報告語言** | 前者改按鈕和菜單；後者改報告正文語言，二者**互不影響** |
| **組合 vs 持倉** | 側欄導航名多爲「組合」；頁面標題多爲「持倉」——同一模塊 |
| **Agent vs 問股** | 側欄多爲「Agent」；頁面標題多爲「問股」——同一模塊 |

更完整的金融用詞治理見 [多語言金融術語指導](../../../financial-terminology-guide.md)。

## 文檔維護說明（給貢獻者）

- 本手冊只寫「怎麼點界面」，不寫部署與密鑰運維。
- 發現界面標籤與手冊不一致時，以**線上界面**為準，並開文檔 PR 修正。
- **每個模塊應寫清**：入口路徑（導航 + 路由 + 深鏈參數）、術語表、逐步操作、使用案例、與相鄰模塊關係。
- **有 UI / 路由 / 文案變更的 PR**：同一變更列車內檢查並更新對應 `docs/ui-manual/*` 分冊與本 README 導航表；中英成對修改。
- 對照源碼時優先核對：`apps/dsa-web/src/routing/routes.ts`、`components/layout/navigation.ts`、`i18n/uiText.ts`、設置 IA `settingsInformationArchitecture.ts`、選股文案 `locales/screening.ts`。
- 擴寫進度：01–13 分冊已覆蓋全部主業務路由；03/05/06/07/10 含「深度操作」對照上千行頁面實現。仍持續按 PR 增量補字段級細節；截圖二進制待 [assets/README.md](../../assets/README.md)（#599）。
