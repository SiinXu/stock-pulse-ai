# StockPulse 界面操作手冊

> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

> **範圍**：Web 工作台與桌面客戶端的**界面操作**。  
> **不包含**：部署、Docker、GitHub Actions、環境變量清單、服務器運維。  
> 安裝與首次填 Key 見 [客戶端安裝與配置](../../../beginner-client-setup.md)（[English](../../../beginner-client-setup_EN.md)）；部署見 [完整配置與部署指南](../../../full-guide.md)。

第一次打開 StockPulse 時，你可能還不熟股票代碼寫法，也不清楚「分析」「信號」「持倉」分別做什麼。下面按使用順序拆開講：點哪裡、會看到什麼、接下來怎麼走。

界面文案若和手冊不一致，以你屏幕上的為準。

> 產品輸出僅供學習與研究，**不構成投資建議**。真實買賣請自行判斷風險與合規要求。
