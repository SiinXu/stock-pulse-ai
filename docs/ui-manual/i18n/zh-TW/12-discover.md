# 12 發現：用 AlphaSift 找候選（實驗功能）


> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

你好。「發現」頁的導航名是 **發現**，頁面標題常常是 **AlphaSift 選股**。

它做的事是：在策略或熱點題材約束下，幫你生成一份 **候選股票短名單**，再交給分析工作台深挖。  
它 **不是**「保證賺錢的薦股黑箱」，目前仍是 **實驗能力**。

> ⚠️ 結果僅供研究與輔助判斷，**不構成投資建議**。交易決策與損益由你自己承擔。  
> 使用前需要：相關能力開啓、後端 AlphaSift 適配層與依賴可用。

---

## 怎麼進入

| 方式 | 路徑 |
| --- | --- |
| 導航 | **研究** → **發現** |
| 地址 | `/research/discover` |
| 命令面板 | 搜「發現」「選股」「AlphaSift」 |
| 舊路徑 | `/screening` 常會跳轉過來 |

可收藏示例：`/research/discover?market=cn&strategy=dual_low&count=3`  
參數不合法時會回落安全默認（實現裏常見默認市場 `cn`、數量 `3` 等）。

---

## 新手要不要用？

| 你的階段 | 建議 |
| --- | --- |
| 還沒跑通第一份個股報告 | **先跳過**，去工作台 |
| 模型已通、想找主題線索 | 可以用熱點題材 |
| 想試策略篩票 | 返回數量先設 3～10 |

## 頁面結構（逛一圈）

| 區域 | 作用 |
| --- | --- |
| 啓用狀態 | 已開啓 / 未開啓 / 適配層不可用 |
| 風險提示 | 實驗聲明，每次都值得掃一眼 |
| 熱點題材 | 題材熱度、階段、發酵路線、概念股（常默認摺疊） |
| 策略選擇 | AlphaSift 策略或自定義參數 |
| 參數 | 市場、策略參數、返回數量 1～100 |
| 運行選股 | 異步任務 + 狀態輪詢 |
| 候選結果 | 摘要、因子、風險、點「分析」 |

## 跟着做

### A. 第一次啓用

1. 進入發現頁。  
2. 若顯示未開啓，點 **開啓 AlphaSift**。  
3. 若適配層不可用：檢查後端依賴、重啓服務或更新桌面端。  
4. 啓用成功後再玩熱點或策略。

### B. 用熱點找線索

1. 展開熱點題材。  
2. 需要新數據時點 **刷新**（別狂點，可能限流）。  
3. 點某個題材，看發酵路線與概念股。  
4. 對感興趣的代碼點 **分析** → 進工作台。  
5. 看到緩存回退/降級/缺字段時，熱度只當弱線索。

### C. 按策略篩一版

1. 選策略（列表失敗時可試手動參數）。  
2. 市場如 A 股，`count` 先 5。  
3. **運行選股**，等完成。  
4. 若提示 LLM 重排失敗、已回退本地因子：列表仍可看，但排序解釋力變弱。  
5. 對前幾名去工作台出報告，再決定是否進自選。

## 常見提示

| 提示方向 | 你可以怎麼理解 |
| --- | --- |
| 缺少 LLM API Key | 先去設置配模型 |
| 請求過於頻繁 | 降頻刷新/提交 |
| 數據源降級 | 結果能看但質量下降 |
| 無交易日曆開市日 | 非交易時段或日曆問題，更保守 |
| 暫無緩存熱點 | 展開後點刷新 |

---

## 使用案例

**主題線索** → 刷新熱點 → 選你懂的行業 → 兩隻概念股分析 → 按 [08](08-reading-reports.md) 讀風險。  
**策略試跑** → count=5 → 讀因子與風險 → 第一名進工作台。  
**開啓失敗** → 先用自選+工作台，不要卡死上手流程。

## 術語

| 術語 | 人話 |
| --- | --- |
| AlphaSift | 內置實驗選股適配層 |
