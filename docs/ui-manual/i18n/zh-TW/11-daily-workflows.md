# 11 日常工作流與應用場景

前面各章講「單個頁面怎麼點」。這一章講 **怎麼串起來用**：按一天/一週的節奏、按角色、按具體目標，把導航、首頁、分析、信號、持倉、問股、設置擰成一套可重複的用法。

原則：

1. **少而穩**：固定幾個入口，先讀結論和風險，再決定深挖。  
2. **同一天同一隻票不要無意義連跑**——既費額度，也難復盤。  
3. **系統不代替下單**：所有輸出僅供研究，**不構成投資建議**。

更細的頁面操作見對應模塊；本章偏「菜譜」和「場景」。完整簡體長本與中英對照以倉庫 `docs/ui-manual/11-daily-workflows.md` 為準；下方為繁體可讀濃縮 + 場景表。

---

## A. 固定節奏

### A1. 每天大約 5 分鐘

1. **首頁**：焦點、待辦、**今日定時任務**（只讀）。  
2. **信號中心**（鈴鐺 / 命令面板 / `/signals`）：只掃 `active`。  
3. 有持倉則看 **組合** 集中度與異常。  
4. 最多 1 隻疑問股：最近報告或問股一句失效條件。

通知先保證一個渠道測通。

### A2. 深度研究 30～60 分鐘

發現（可選）→ 工作台 brief → 按 08 讀報告 → 歷史趨勢 → 問股 → 簡單價格規則 → 持倉對數量。

### A3. 周末復盤自己的用法

回測 → 信號再評估 → 輕微調設置；導出一次配置備份。

### A4. 從零到第一份報告

模型測通 → 自選 1 碼 → 工作台 1 隻 brief → 只讀結論與三條風險 →（可選）測推送。

---

## B. 按角色

| 角色 | 用法重點 |
| --- | --- |
| 純新手 | 一模型 + 一隻票 + 默認策略 + brief |
| 上班族 | 調度 + 單渠道推送 + 規則只盯重倉；早上看首頁任務 |
| 記賬型 | 組合為真，信號 `scope=holdings`，每周復盤 |
| 研究向 | 歷史對比 + 固定問股模板 + 周末回測 |
| 多市場 | A/`hk`/美股代碼習慣；時區與靜默時段對準盯盤時間 |

## C. 場景菜譜

| 我想… | 去哪 | 注意 |
| --- | --- | --- |
| 第一份報告 | 工作台 1× brief | 別一上來 detailed×10 |
| 市場溫度 | 大盤復盤 | 不當個股指令 |
| 沒標的 | 發現 → 工作台 | 實驗能力 |
| 到價提醒 | 信號 → 規則 | 先試運行 |
| 手機推送 | 設置 → 通知 | 先一個渠道 |
| 每天自動跑 | 設置 → 調度 | 進程要長運行 |
| 對真實倉位 | 組合 + holdings | 不會自動買賣 |
| 報告某段不懂 | 繼續問股 | 一次一事 |
| 兩隻對比 | 問股寫清兩代碼 | 防串上下文 |
| 只看圖 | `/stocks/代碼` | AI 結論仍回工作台 |
| 自己準不準 | 回測 + 再評估 | 改用法不改下一把賭 |
| 省額度 | brief、少批量、問股手術刀 | 歷史對比代替連跑 |

---

## D. 組合技（摘要）

1. **漏斗**：發現 5 → brief 批量 → 精讀 1～2 → 規則 0～1 → 再記賬。  
2. **雙讀**：大盤氣質 + 個股風險，不把「偏多」譯成滿倉。  
3. **骨架 + 手術刀**：brief 後問股只打一個孔。  
4. **靜默時段**：夜間安靜；用推送歷史分清沒觸發 / 渠道失敗 / 被靜默。  
5. **命令面板**：分析、信號、持倉、設置、代碼。  
6. **三件套**：最新報告 + 一條信號/規則 +（若持有）持倉行。

---

## E. 問股花樣問法

- 「只討論 600519：失效條件條目；收盤跌破何價應重評？」  
- 「已持有 hk00700：加減倉前觀察條件，不要倉位比例。」  
- 「三條概括 AAPL 結論與風險，不要指標堆砌。」  
- 「請切換到 300750，不要混入 600519。」  

反面：「全面分析並告訴我能不能滿倉」。

---

## F. 反模式

| 反模式 | 更好做法 |
| --- | --- |
| 同一隻一天跑 10 次 | 1 次 + 問股 + 歷史 |
| 50 條規則從不試運行 | 先 1 條試運行 |
| 只看「買入」標籤 | 固定閱讀順序 |
| 不保存就測連接 | 保存 → 測試 → 離開 |
| 自選 200 全 detailed 日更 | 池子 / 觀察 / 重倉分層 |
