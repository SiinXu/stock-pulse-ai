# 11 日常工作流：如果只能記住一篇，記住這篇


> 本頁為**繁體中文**操作手冊。產品介面亦可切換為繁體；若螢幕標籤與手冊不一致，**以介面為準**。

你好。前面每一章都在講「單個房間怎麼用」。這一章把它們串成 **每天可以重複的節奏**。

原則只有一句：**少而穩**。固定幾個入口，先讀結論與風險，再決定要不要深挖。同一天對同一隻股票無意義連跑十幾次，既費錢，也容易把自己搞焦慮。

> ⚠️ 所有輸出僅供研究，**不構成投資建議**。

---

## A. 每天大約 5 分鐘（維護型）

1. 打開 **首頁**（`/`）：看焦點和待辦。  
2. 打開 **信號中心**（鈴鐺 / 命令面板 / `/signals`——不在一級側欄）：只掃 `active`。  
3. 若有持倉：打開側欄 **組合**（`/portfolio`），看集中度與異常。  
4. 對仍有疑問的 **1 只**：打開最近報告，或 **Agent / 問股** 只問一句失效條件。

通知先保證一個渠道能收到，再慢慢加（見 [10 設置](10-settings.md)）。

## B. 深度研究一隻股票（30～60 分鐘）

0. （可選）沒有標的時，先去 [12 發現](12-discover.md) 找候選。  
1. **研究 → 分析工作台** 提交該股（可先 brief / 新手）。  
2. 按 [08 閱讀報告](08-reading-reports.md) 的順序讀。  
3. 用歷史趨勢看是否翻燒餅。  
4. 問股追問觀察點與失效條件（寫清代碼）。  
5. 需要盯盤時，在 `/signals?tab=rules` 建簡單價格規則。

## C. 周末復盤自己的用法（不是復盤行情本身）

1. **研究 → 回測**（`/research/backtest`）看歷史建議的大致方向表現。  
2. 信號中心 **再評估與統計**（`/signals?tab=review`）看反饋與後驗。  
3. 回設置微調模型或默認策略——**不要**靠瘋狂改自選製造噪音。

## 場景速查

| 我想… | 去哪 | 溫柔提醒 |
| --- | --- | --- |
| 儘快出第一份報告 | 分析工作台 | 一隻票 + 新手/brief |
| 看市場溫度 | 大盤復盤 | 別當個股下單指令 |
| 找候選 | 發現 | 實驗能力，再進工作台 |
| 到價提醒 | 信號中心 → 規則 | 先簡單價格條件 |
| 記賬 | 組合/持倉 | 先建賬戶 |
| 改模型 | 設置 → AI 與模型 | 保存後再測試 |
| 看行情圖 | `/stocks/代碼` | 不是完整 AI 報告 |

---

## 常見卡住

**信號中心是空的？** 先成功跑完個股分析。  
**持倉沒有 AI 建議？** 異步加載或沒有 active；對持倉跑分析即可。  
**設置填了仍提示缺口？** 多半沒保存或測試未通過。  
**問股發不出去？** 查模型與是否本地 CLI 限制工具調用。
