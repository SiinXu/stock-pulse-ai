# 10 Einstellungen

Viele Felder—zuerst nur drei Wins:

1. **Modell verbindet**  
2. **Watchlist hat Codes**  
3. **(Optional) ein Kanal mit Test-Push**  

> Nur UI-Klicks. Deployment in anderen Guides.  
> **Speichern → testen → verlassen**.

## Öffnen

`/settings` · Guided setup auf Home · `section=ai_models&view=connections`

## Benachrichtigungen

Kanäle oft als **Karten**. Einen öffnen, Token füllen → **Test-Push** → **Speichern**.  
**Channel-Plugins** können deploy-seitig extra Kanäle laden (`docs/notifications.md`).

## Zeitplanung

**System & Security → Scheduling**: Auto-Analyse an/aus, Uhrzeit, nächster Lauf, ggf. „jetzt einmal“.  
Home **Today’s scheduled tasks** ist nur lesend. Details: `docs/scheduled-tasks.md`.

## Investment-Framework

Versioniertes persönliches Framework: **API/Backend zuerst**. Meist noch kein volles Web-Editor-UI. Vertrag: `docs/personal-investment-framework.md`.

## Model packs (manche Builds / in Arbeit)

Wenn **Import pack** sichtbar: versioniertes lokales Pack importieren → Snapshot binden → aktivieren. Ohne Button nichts erzwingen. Einstieg: **AI & Models → Local models**.
