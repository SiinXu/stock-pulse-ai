# 14 Settings field quick reference
This chapter summarizes in-product field help for Settings. The **Chinese** chapter is generated from the same product help source and is more complete for field wording.
- Full bilingual field help also appears **inside the Settings UI** when you open a field’s help control.
- Tutorial-style setup: [10 Settings](10-settings_EN.md).
- Chinese field tables: [14 设置字段速查](14-settings-fields.md).

## How to use this reference
1. Open **Settings** and the relevant section.
2. If unsure about a control, open the in-app help on that field (same content family as this appendix).
3. Always **Save**, then test connection / test push.
