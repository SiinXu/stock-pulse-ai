# 12 发现：用 AlphaSift 找候选（实验功能）

你好。「发现」页的导航名是 **发现**，页面标题常常是 **AlphaSift 选股**。

它做的事是：在策略或热点题材约束下，帮你生成一份 **候选股票短名单**，再交给分析工作台深挖。  
它 **不是**「保证赚钱的荐股黑箱」，目前仍是 **实验能力**。

> ⚠️ 结果仅供研究与辅助判断，**不构成投资建议**。交易决策与损益由你自己承担。  
> 使用前需要：相关能力开启、后端 AlphaSift 适配层与依赖可用。

---

## 怎么进入

| 方式 | 路径 |
| --- | --- |
| 导航 | **研究** → **发现** |
| 地址 | `/research/discover` |
| 命令面板 | 搜「发现」「选股」「AlphaSift」 |
| 旧路径 | `/screening` 常会跳转过来 |

可收藏示例：`/research/discover?market=cn&strategy=dual_low&count=3`  
参数不合法时会回落安全默认（实现里常见默认市场 `cn`、数量 `3` 等）。

---

## 新手要不要用？

| 你的阶段 | 建议 |
| --- | --- |
| 还没跑通第一份个股报告 | **先跳过**，去工作台 |
| 模型已通、想找主题线索 | 可以用热点题材 |
| 想试策略筛票 | 返回数量先设 3～10 |

## 页面结构（逛一圈）

| 区域 | 作用 |
| --- | --- |
| 启用状态 | 已开启 / 未开启 / 适配层不可用 |
| 风险提示 | 实验声明，每次都值得扫一眼 |
| 热点题材 | 题材热度、阶段、发酵路线、概念股（常默认折叠） |
| 策略选择 | AlphaSift 策略或自定义参数 |
| 参数 | 市场、策略参数、返回数量 1～100 |
| 运行选股 | 异步任务 + 状态轮询 |
| 候选结果 | 摘要、因子、风险、点「分析」 |

## 跟着做

### A. 第一次启用

1. 进入发现页。  
2. 若显示未开启，点 **开启 AlphaSift**。  
3. 若适配层不可用：检查后端依赖、重启服务或更新桌面端。  
4. 启用成功后再玩热点或策略。

### B. 用热点找线索

1. 展开热点题材。  
2. 需要新数据时点 **刷新**（别狂点，可能限流）。  
3. 点某个题材，看发酵路线与概念股。  
4. 对感兴趣的代码点 **分析** → 进工作台。  
5. 看到缓存回退/降级/缺字段时，热度只当弱线索。

### C. 按策略筛一版

1. 选策略（列表失败时可试手动参数）。  
2. 市场如 A 股，`count` 先 5。  
3. **运行选股**，等完成。  
4. 若提示 LLM 重排失败、已回退本地因子：列表仍可看，但排序解释力变弱。  
5. 对前几名去工作台出报告，再决定是否进自选。

## 常见提示

| 提示方向 | 你可以怎么理解 |
| --- | --- |
| 缺少 LLM API Key | 先去设置配模型 |
| 请求过于频繁 | 降频刷新/提交 |
| 数据源降级 | 结果能看但质量下降 |
| 无交易日历开市日 | 非交易时段或日历问题，更保守 |
| 暂无缓存热点 | 展开后点刷新 |

---

## 使用案例

**主题线索** → 刷新热点 → 选你懂的行业 → 两只概念股分析 → 按 [08](08-reading-reports.md) 读风险。  
**策略试跑** → count=5 → 读因子与风险 → 第一名进工作台。  
**开启失败** → 先用自选+工作台，不要卡死上手流程。
