# 12 Discover: AlphaSift candidates (experimental)

Nav **Discover**, page title often **AlphaSift screening**. Builds a **shortlist**, then you deepen names on the Workbench. Experimental—not a guaranteed picker.

> Research only — **not investment advice**. Needs AlphaSift enabled and a healthy adapter.

## Open

**Research → Discover**, `/research/discover`. Example: `?market=cn&strategy=dual_low&count=3`.

## Beginners

Skip until your first Workbench report works. Then try hotspots or a strategy with `count` 3–10.

## Flow

Enable AlphaSift → hotspots and/or strategy run → candidates → **Analyze** → Workbench report → optional signals.

## Tips

Don’t spam hotspot refresh (rate limits). LLM rerank fallback to local factors still yields a list with weaker ranking story. Missing LLM key → Settings first.
