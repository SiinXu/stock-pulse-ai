# 首页仪表盘布局

首页挂载一块独立的**可定制仪表盘**，覆盖四个关键小组件：

| 小组件 id | 内容 |
| --- | --- |
| `watchlist` | 自选分组（既有首页区块，评分请求成功时显示 AI 评分）。评分请求失败是可重试的错误，不会伪装成未分析的空列表。 |
| `portfolio_health` | 只读日度组合健康快照 |
| `alerts` | 已触发告警计数，深链到告警中心 |
| `recent_reports` | 最近个股分析报告 |

零配置首启 / 就绪面板与**今日焦点**不在此板内，不受布局偏好重排。

## 偏好模型

- 存储键：浏览器 `localStorage` 的 `dsa.home.dashboardLayout.v1`（按浏览器配置文件）。
- Schema 版本 `1`，带单调递增 `revision`。
- 每个已知小组件 id 恰好出现一次，并带 `visible` 标志。
- 安全边界：
  - 丢弃未知 id；缺失 id 按默认可见性追加。
  - 至少保留一个可见小组件。
  - 重排载荷必须包含全部已知 id 且各一次。

## 并发

客户端写操作沿用自选分组的 revision CAS：每次写入携带期望 revision，成功后自增，冲突则失败并重载（含多标签 `storage` 事件）。页内短租约避免重叠写入。

## 交互与无障碍

- **桌面**：仅在「自定义」模式下从拖拽手柄开始拖动；同一手柄支持上下方向键。
- **移动端**：隐藏拖拽手柄；提供显式上移 / 下移按钮，不依赖拖拽。
- 显示/隐藏遵守最少可见约束；最后一个可见小组件不可隐藏。
- 实况区域播报重排、显隐与恢复默认成功。
- 空板（仅在损坏存储异常恢复时）提供恢复默认。

## 集成边界

`HomeDashboardLayout` 为独立容器 + 偏好 store。首页只传入小组件节点与既有注意力数据，不重写拖拽或存储。组合健康只读调用 `GET /api/v1/portfolio/health`（404 → 空态）。

## 回滚

移除首页挂载与布局偏好键即可。旧客户端忽略 `dsa.home.dashboardLayout.v1`。无需后端迁移。
