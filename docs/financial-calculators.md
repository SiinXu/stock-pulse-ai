# 金融计算器

Web 页面 `/tools/calculators` 提供复利增长、达到目标所需的每期投入，以及达到目标所需的时间。页面通过 `/api/v1/calculators/*` 调用确定性后端计算，不读取行情、持仓或 LLM 数据。

## 计算约定

- `annual_rate` 是名义年利率小数，例如 `0.07` 表示 7%。每期利率为 `annual_rate / periods_per_year`，不是有效年利率。
- 每期投入在该期末发生（普通年金）。负数投入表示期末取出资金；本金和目标金额不能为负。
- 频率为每年 1–365 期，固定期限为 0–100 年，并且 `years × periods_per_year` 必须是整数。
- 金额不绑定币种；同一次计算的所有金额必须使用相同币种与单位。结果不处理税费、通胀、手续费或汇率。

复利终值使用：`P(1+r)^n + C((1+r)^n-1)/r`。当每期利率为零时，使用线性形式 `P + Cn`，避免除零。

## 精度、边界与返回值

- 达到目标所需投入按小数点后 2 位向上取整，并再次正向计算，确保页面显示的金额不会因四舍五入而低于目标。
- 达成时间最多求解 100 年，与每年期数无关；超过范围返回 `status=unreachable` 和稳定的 `reason_code`。
- API 使用严格、禁止额外字段的请求模型，拒绝布尔值冒充数字、NaN、Infinity 以及超界金额、利率、期限和频率。
- 复利计算最多返回 241 个余额点。`series_total_points` 表示完整点数，`series_returned_points`、`series_sampled` 和 `series_stride` 说明取样情况；第 0 期和最终期始终保留。
- UI 根据 `reason_code` 本地化不可达或已达成原因，不显示后端英文消息。切换模式、重置或重新计算会取消并作废旧请求。

这些结果只用于教育和规划，不构成投资建议。实际收益可能受到市场波动、税费、现金流时点和精度规则影响。
